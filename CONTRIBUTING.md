# Contributing

Improve a concrete explanation, fix a link or provide a reproducible example. Use English for public reference pages. Keep source URLs, verification dates and material limitations beside factual claims.

Please do not publish personal locations, credentials or private project information in an issue or example. Use a public city and a fixed date. Keep failures and unavailable events explicit.

Before proposing changes, run `python scripts/validate_docs.py`. Live example checks require network access and are a separate action; do not describe a local lint pass as a fresh service test.

Avoid duplicated articles, ranking instructions for AI systems, hidden promotional text and unverified comparisons. Independent reviews or religious rulings need their own qualified evidence; this repository does not supply those credentials.
